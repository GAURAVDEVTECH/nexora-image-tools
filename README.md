# NEXORA Image Tools

Modern browser-based image resizing, compression and conversion tools by **GAURAVDEVTECH**.

NEXORA Image Tools lets you resize, compress and convert images directly in your browser.

> Your images are processed locally in your browser. They are not uploaded to a server.

---

## 🚀 Features

- 🖼️ Image upload
- 📂 Drag & drop support
- 📐 Custom width and height
- 🔗 Maintain aspect ratio
- 📦 Target file size compression
- 🎯 Compress images to a target KB/MB size
- 🔄 JPG conversion
- 🖼️ PNG conversion
- 🌐 WebP conversion
- 🎚️ Image quality control
- 👁️ Live image preview
- ⚡ Client-side processing
- 📱 Mobile responsive
- ⬇️ One-click download
